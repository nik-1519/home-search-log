Redfin quick-add bookmarklet
While viewing a Redfin listing page in Safari, tap this to pull beds, baths, sqft, lot, price, year built, and the assigned high/middle school straight into this log — no typing. It reads whatever Redfin has displayed on the page, so it can occasionally miss a field if Redfin changes their layout; anything it misses you can fill in from Edit.
Set up once on iOS (Safari doesn't support dragging to a bookmarks bar):
1. Bookmark any page first — tap Share → Add Bookmark.
2. Go to Bookmarks, tap Edit, tap that new bookmark.
3. Rename it "Add to Home Log," then replace the Address field with the code below (tap Copy, then paste over the URL).
4. Save. From now on, open a Redfin listing → tap the address bar → type "Add to Home Log" → tap it.
